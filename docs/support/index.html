为什么无法截图？

请先确认 macOS 已为 StackShot 授予屏幕录制权限。未授权时，应用无法读取屏幕内容，也无法进行滚动截图或 OCR。

辅助功能权限是必须的吗？

不是。它只会提升鼠标下窗口识别的准确性。即使不授权，你仍然可以手动框选截图。

“识别并翻译”为何会打开系统应用？

当前可上架版本采用安全的翻译接力设计：StackShot 先识别文字并复制到剪贴板，再打开系统“翻译”应用继续处理。

滚动截图失败怎么办？

先确认目标窗口可以连续滚动，并尝试减小捕获区域或关闭遮挡窗口。若问题稳定复现，请在 Issues 中附上复现步骤和 macOS 版本。

提交问题时建议附带的信息

  • macOS 版本和设备架构，例如 Apple Silicon 或 Intel。
  • StackShot 版本号与构建号。
  • 你执行的功能路径，例如区域截图、窗口截图、滚动截图或 OCR。
  • 能稳定复现问题的步骤，最好附带截图或录屏。

為什麼無法截圖？

請先確認 macOS 已為 StackShot 授予螢幕錄製權限。未授權時，App 無法讀取畫面內容，也無法進行捲動截圖或 OCR。

輔助使用權限是必須的嗎？

不是。它只會提升游標下視窗辨識的準確性。即使不授權，你仍可手動框選截圖。

為什麼「辨識並翻譯」會打開系統 App？

目前可上架版本採用安全的翻譯接力設計：StackShot 先辨識文字並複製到剪貼簿，再打開系統「翻譯」App 繼續處理。

捲動截圖失敗怎麼辦？

請先確認目標視窗可以連續捲動，並嘗試縮小擷取區域或關閉遮擋視窗。若問題可穩定重現，請在 Issues 中附上重現步驟和 macOS 版本。

  • StackShot 版本號與建置號。
  • 你執行的功能路徑，例如區域截圖、視窗截圖、捲動截圖或 OCR。
  • 可穩定重現問題的步驟，最好附上截圖或錄屏。

Why can't StackShot capture the screen?

Make sure Screen Recording permission is granted in macOS settings. Without it, the app cannot read screen content for screenshots, scrolling capture, or OCR.

Is Accessibility required?

No. Accessibility is optional and only improves hovered-window detection. Manual region capture still works without it.

Why does Recognize & Translate open a system app?

The App Store-safe design recognizes text locally, copies it to the clipboard, and then opens the system Translate app for the next step.

What should I try if scrolling capture fails?

Confirm that the target window can scroll continuously, reduce the capture area, and close overlapping windows. If the issue is reproducible, include steps and your macOS version in the report.

Helpful details to include in a report

  • Your macOS version and machine architecture, such as Apple Silicon or Intel.
  • The StackShot version and build number.
  • The workflow you were using, such as region capture, window capture, scrolling capture, or OCR.
  • Steps to reproduce, ideally with a screenshot or screen recording.

なぜ画面をキャプチャできないのですか？

macOS の設定で StackShot に画面収録権限が与えられているか確認してください。未許可ではスクリーンショット、スクロールキャプチャ、OCR に必要な画面内容を取得できません。

アクセシビリティは必須ですか？

必須ではありません。ポインタ下のウインドウ判定精度を高めるための任意権限です。未許可でも手動範囲選択は使えます。

なぜ「認識して翻訳」でシステムアプリが開くのですか？

公開向けの安全な設計では、StackShot が文字をローカルで認識してクリップボードへコピーし、その後システムの「翻訳」アプリへ処理を引き継ぎます。

スクロールキャプチャが失敗したら？

対象ウインドウが連続スクロール可能か確認し、キャプチャ範囲を狭めるか重なっているウインドウを閉じてください。再現する場合は、手順と macOS のバージョンを報告してください。

報告に含めると役立つ情報

  • macOS のバージョンと、Apple Silicon か Intel か。
  • StackShot のバージョンとビルド番号。
  • 範囲キャプチャ、ウインドウキャプチャ、スクロールキャプチャ、OCR など、使用していた機能経路。
  • 再現手順。できればスクリーンショットや画面収録も添付してください。
