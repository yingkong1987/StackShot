## StackShot 官网全面重设计

完成了 StackShot GitHub Pages 网站的全面视觉重构：

### 变更内容
- **全新视觉主题**：从 Vermeer 暖象牙风格改为科技感深色主题（#070b12 背景 + #00d4ff 青色霓虹）
- **动态效果**：
  - 动态网格背景（CSS animation 漂移）
  - 动态环境光 orbs（径向渐变）
  - Hero 区域粒子效果（Canvas API，带连线）
  - 产品演示窗口悬浮动画（float keyframes）
  - 卡片滚动出现动画（IntersectionObserver）
- **语言切换器重构**：从横排按钮列表改为下拉菜单，JS 动态构建
- **语言扩展**：从 11 种扩展到全球 TOP15：新增 Hindi、Indonesian、Italian、Dutch
- **自动语言检测**：通过 `navigator.languages`（按优先级排序）+ localStorage + URL 参数三层检测
- **三个页面均已更新**：index.html / privacy/index.html / support/index.html

### 技术实现
- CSS：纯 CSS 变量驱动，glassmorphism 效果，所有动画无 JS 依赖
- JS：模块化，`buildDropdown()` 动态注入语言菜单，`initParticles()` Canvas 粒子网络
- 完全静态，零依赖，兼容 GitHub Pages
