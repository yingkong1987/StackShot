信頼を前提に設計

プロダクトの境界もワークフローに表れる

機能だけでなく、どこまでをアプリが担うかも明確にしています。

ローカル優先

権限を最小化

画面収録はスクリーンショットとスクロールキャプチャにのみ使用します。

境界が明確

「認識して翻訳」は文字をローカルで認識し、その後 Apple の公開 Translation フレームワークでアプリ内翻訳を行います。
