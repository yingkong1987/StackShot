Capture workflows

Region capture, window capture, and scrolling screenshots cover web pages, documents, and long conversations.

Annotation tools

Mark up captures with rectangles, circles, arrows, pen strokes, mosaic, text, and emoji.

OCR pipeline

Recognize text from captured content and surface it for copy, export, or translation handoff.

Translation workflow

StackShot recognizes text first and then hands the recognized content to the system Translate app for the next step.

StackShot の公開情報と公式リンク

公式公開リンク

プライバシーポリシー、サポート情報、製品トップページをそれぞれ公開しています。

キャプチャ機能

範囲キャプチャ、ウインドウキャプチャ、スクロール長尺キャプチャで Web ページや書類をまとめて記録できます。

注釈ツール

矩形、円、矢印、ペン、モザイク、テキスト、絵文字で撮影後すぐに注釈を追加できます。

OCR ワークフロー

取得した画像から文字を認識し、コピーや書き出し、翻訳への引き継ぎに使えます。

翻訳ワークフロー

StackShot は文字を認識した後、その結果をシステムの「翻訳」アプリへ引き継ぎます。
