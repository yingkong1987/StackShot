ShadowGuessKids Privacy Policy

This policy explains how ShadowGuessKids handles data. The short version: the app is fully offline, contains no ads, no in-app purchases, no tracking, and uses no server — children can play without ever sending a byte off the device.

Always offline

The app has no networking features. No account is required, and no usage data is uploaded to any server.

Camera & microphone (Video Voice mode only)

These are used only when you choose the "Video Voice" mode and grant the permissions. Capture is used solely for real-time on-device effects, gameplay, and recordings that you start yourself. Frames and audio do not leave the device.

Speech recognition on device

Voice input is recognized entirely on the device. The app does not use a cloud speech-recognition service.

Playback videos

After a round, a temporary recording can be replayed inside the app. The file is only written to your Photo Library if you tap the explicit "Save" button. Leaving the playback page automatically deletes the temporary file.

What we don't do

  • No accounts, no sign-in, no analytics SDKs.
  • No ads, no pop-ups, and no in-app purchases.
  • No ad tracking or behavioral profiling.
  • No upload of camera, microphone, or voice data.
  • App settings are stored only on the device.

Third-party services

  • Apple Speech Recognition — used only in "Video Voice" mode and runs on the device.
  • GitHub Pages — this public page is hosted on GitHub Pages. GitHub may process basic web request logs under its own policies.
QUESTIONS?

Contact us

If you have questions about this policy or how your child's data is handled, email us directly.

support@stackpaste.cn

We usually reply within 1–2 business days.

隐私政策 · 更新于 2026-07-22

影子猜猜乐 隐私政策

本政策说明影子猜猜乐如何处理数据。简要结论：应用完全离线、不包含广告、不内购、不做追踪、不依赖服务器——孩子使用时不会把任何数据发到开发者侧。

始终离线

应用没有任何联网功能。不需要注册账户，也不会将使用数据上传到任何服务器。

摄像头与麦克风（仅「视频语音」模式）

只有在你主动选择「视频语音」模式并授权时，才会使用摄像头与麦克风，且仅用于设备上的实时特效、答题与由你主动开始的录像。画面与音频都不会离开设备。

设备端语音识别

语音识别完全在设备本地完成，不使用任何云端语音识别服务。

回放视频

完成一轮后可在应用内回看录像。临时录像仅在你主动点击「保存」后才会写入相册；离开回看页后，临时文件会自动删除。

我们不会做的事

  • 不需要注册账户，不集成任何统计分析 SDK。
  • 不包含任何广告、弹窗或内购。
  • 不做广告追踪或行为画像。
  • 不上传摄像头、麦克风或语音相关数据。
  • 应用设置仅保存在本机。

第三方与外部服务

  • Apple 语音识别：仅在「视频语音」模式使用，且在设备端运行。
  • GitHub Pages：本公开页面托管于 GitHub Pages。访问本页面时，GitHub 可能依据其自身政策处理基础的网页请求日志。
