StackShot 隐私政策

StackShot 是一款面向 macOS 的本地优先截图工具。我们尽量只在你主动触发相关功能时访问系统权限，并优先在设备本机处理截图内容。

简要结论

StackShot 不要求创建账户，不内置广告 SDK，不自动把你的截图上传到远程服务器，也不提供网络同步截图内容的机制。

我们访问哪些权限

  • 屏幕录制：用于截图、滚动截图，以及对已捕获内容进行后续编辑和 OCR。
  • 辅助功能：可选权限，仅用于更准确识别鼠标下的前台窗口。未授权时，手动框选截图仍可正常使用。

我们如何处理截图内容

  • 截图编辑、窗口识别、OCR 和大部分图像处理默认都在本机完成。
  • 只有在你点击复制、分享、保存或 OCR 翻译时，应用才会把图像或文字写入剪贴板或导出到你选择的位置。
  • 偏好设置例如语言、Dock 显示和快捷键只保存在当前 Mac 的本地偏好中。

“识别并翻译”如何工作

  • StackShot 会先在设备上识别截图中的文字。
  • 识别结果会复制到剪贴板，然后应用尝试打开系统“翻译”应用。
  • 后续的翻译处理不由 StackShot 直接完成，而由系统应用或你选择的翻译应用处理。

我们不会做的事

  • 不会要求你注册账户来使用基本截图功能。
  • 不会在后台自动开始录屏。
  • 不会内置把截图上传到开发者服务器的自动同步逻辑。
  • 不会出售你的截图、OCR 文本或使用习惯数据。

第三方与外部服务

如果你在 OCR 翻译接力后继续使用系统“翻译”应用，后续翻译相关的数据处理将遵循 Apple 或对应翻译应用提供方的隐私政策，而不是由 StackShot 控制。

本公开页面托管在 GitHub Pages 上。访问本页面时，GitHub 可能会依据其自身政策处理基础的网页请求日志。

联系我们

如果你对本隐私政策有疑问，或需要提交与使用体验相关的问题，请访问支持页或通过 GitHub Issues 联系。

StackShot 隱私政策

StackShot 是一款面向 macOS 的本機優先截圖工具。我們只在你主動使用相關功能時存取系統權限，並優先在裝置本機處理截圖內容。

簡要結論

StackShot 不要求建立帳號，不內建廣告 SDK，不會自動把你的截圖上傳到遠端伺服器，也不提供網路同步截圖內容的機制。

我們會使用哪些權限

  • 螢幕錄製：用於截圖、捲動截圖，以及對已擷取內容進行後續編輯與 OCR。
  • 輔助使用：可選權限，只為了更準確辨識游標下的前景視窗。未授權時，手動框選截圖仍可正常使用。

我們如何處理截圖內容

  • 截圖編輯、視窗辨識、OCR 與大部分影像處理預設都在本機完成。
  • 只有當你點擊複製、分享、儲存或 OCR 翻譯時，App 才會把影像或文字寫入剪貼簿，或匯出到你選擇的位置。
  • 偏好設定例如語言、Dock 顯示與快捷鍵只保存在目前這台 Mac 的本地偏好中。

「辨識並翻譯」如何運作

  • StackShot 會先在裝置上辨識截圖中的文字。
  • 辨識結果會先複製到剪貼簿，之後 App 會嘗試打開系統「翻譯」App。
  • 後續翻譯處理不由 StackShot 直接完成，而由系統 App 或你選擇的翻譯工具處理。

我們不會做的事

  • 不會要求你建立帳號才能使用基本截圖功能。
  • 不會在背景自動開始錄屏。
  • 不會內建把截圖上傳到開發者伺服器的自動同步邏輯。
  • 不會出售你的截圖、OCR 文字或使用習慣資料。

第三方與外部服務

如果你在 OCR 翻譯接力後繼續使用系統「翻譯」App，後續翻譯相關資料處理將遵循 Apple 或對應翻譯服務提供方的隱私政策，而不是由 StackShot 控制。

StackShot Privacy Policy

StackShot is a local-first screenshot tool for macOS. We access system permissions only when you intentionally use related features, and we process captured content on-device whenever possible.

Short version

StackShot does not require an account, does not embed ad SDKs, does not automatically upload your screenshots to a remote server, and does not provide a cloud sync path for captured content.

Permissions we use

  • Screen Recording: used for screenshots, scrolling screenshots, and editing or OCR on captured content.
  • Accessibility: optional, used only to improve hovered-window detection under the pointer. Manual region capture still works without it.

How captured content is handled

  • Editing, window detection, OCR, and most image processing are done locally on your Mac.
  • Images or text are written to the clipboard or exported to disk only when you choose Copy, Share, Save, or OCR Translate.
  • Preferences such as language, Dock visibility, and shortcuts are stored locally on the current Mac.

How Recognize & Translate works

  • StackShot recognizes text from captured content on-device.
  • The recognized text is copied to the clipboard and the app attempts to open the system Translate app.
  • Any translation after that handoff is handled by Apple or by the translation app you continue with, not directly by StackShot.

What we do not do

  • We do not require an account for core screenshot workflows.
  • We do not start recording automatically in the background.
  • We do not ship automatic sync logic that uploads captures to a developer-operated server.
  • We do not sell your screenshots, OCR text, or usage habits.

Third-party and external services

If you continue into the system Translate app after the OCR translation handoff, any later translation-related data handling follows Apple's policies, or the policies of the translation tool you choose, rather than StackShot's own processing.

This public site is hosted on GitHub Pages. GitHub may process basic web request logs for the page under its own policies.

Contact

If you have a question about this policy or want to report a product issue, use the support page or contact the project through GitHub Issues.

StackShot プライバシーポリシー

StackShot は macOS 向けのローカル優先スクリーンショットツールです。関連機能をあなたが使うときだけシステム権限にアクセスし、可能な限り取得した内容をデバイス上で処理します。

要点

StackShot はアカウント登録を要求せず、広告 SDK を組み込まず、取得したスクリーンショットを自動的に遠隔サーバーへ送信せず、クラウド同期機能も提供しません。

使用する権限

  • 画面収録: スクリーンショット、スクロールキャプチャ、取得済み画像の編集や OCR に使用します。
  • アクセシビリティ: 任意権限で、ポインタ下の最前面ウインドウ判定の精度向上だけに使います。未許可でも手動範囲選択は利用できます。

取得した内容の扱い

  • 編集、ウインドウ判定、OCR、ほとんどの画像処理はこの Mac 上で完結します。
  • 画像や文字をクリップボードへ書き込んだり、保存先へ書き出したりするのは、コピー、共有、保存、OCR 翻訳をあなたが選んだときだけです。
  • 言語設定、Dock 表示、ショートカットなどの設定は現在の Mac のローカル設定として保存されます。

「認識して翻訳」の動作

  • StackShot は取得した内容の文字をデバイス上で認識します。
  • 認識した文字をクリップボードへコピーし、その後システムの「翻訳」アプリを開こうとします。
  • その後の翻訳処理は StackShot ではなく、Apple またはあなたが使う翻訳アプリ側で行われます。

行わないこと

  • 基本的なスクリーンショット機能のためにアカウント作成を求めません。
  • バックグラウンドで自動的に録画を始めません。
  • 取得内容を開発者運営サーバーへ自動アップロードする同期ロジックを組み込みません。
  • スクリーンショット、OCR テキスト、利用傾向を販売しません。

外部サービスについて

OCR 翻訳の引き継ぎ後にシステムの「翻訳」アプリを使い続ける場合、その後の翻訳関連のデータ処理は StackShot ではなく Apple または利用先アプリのポリシーに従います。
