StackShot 隐私政策

StackShot 是一款面向 macOS 的本地优先截图工具。我们尽量只在你主动触发相关功能时访问系统权限，并优先在设备本机处理截图内容。

简要结论

StackShot 不要求创建账户，不内置广告 SDK，不自动把你的截图上传到远程服务器，也不提供网络同步截图内容的机制。

我们访问哪些权限

  • 屏幕录制：用于截图、滚动截图，以及对已捕获内容进行后续编辑和 OCR。

我们如何处理截图内容

  • 截图编辑、窗口识别、OCR 和大部分图像处理默认都在本机完成。
  • 只有在你点击复制、分享、保存或 OCR 翻译时，应用才会把图像或文字写入剪贴板或导出到你选择的位置。
  • 偏好设置例如语言、Dock 显示和快捷键只保存在当前 Mac 的本地偏好中。

“识别并翻译”如何工作

  • StackShot 会先在设备上识别截图中的文字。
  • 在支持的 macOS 版本中，应用会通过 Apple 官方 Translation 框架在应用内完成翻译；首次使用某些语言对时，系统可能提示下载语言资源。
  • 根据 Apple 的框架说明，Apple 可能会收集不包含原文内容的使用与性能指标，例如 App Bundle ID 与源/目标语言。

我们不会做的事

  • 不会要求你注册账户来使用基本截图功能。
  • 不会在后台自动开始录屏。
  • 不会内置把截图上传到开发者服务器的自动同步逻辑。
  • 不会出售你的截图、OCR 文本或使用习惯数据。

第三方与外部服务

当你使用内置 OCR 翻译时，翻译流程由 Apple 官方 Translation 框架在应用内执行。根据 Apple 的框架说明，Apple 可能处理不包含原文内容的使用与性能指标，例如 App Bundle ID 与源/目标语言。

StackShot Privacy Policy

StackShot is a local-first screenshot tool for macOS. We access system permissions only when you intentionally use related features, and we process captured content on-device whenever possible.

Short version

StackShot does not require an account, does not embed ad SDKs, does not automatically upload your screenshots to a remote server, and does not provide a cloud sync path for captured content.

Permissions we use

  • Screen Recording: used for screenshots, scrolling screenshots, and editing or OCR on captured content.

How captured content is handled

  • Editing, window detection, OCR, and most image processing are done locally on your Mac.
  • Images or text are written to the clipboard or exported to disk only when you choose Copy, Share, Save, or OCR Translate.
  • Preferences such as language, Dock visibility, and shortcuts are stored locally on the current Mac.

How Recognize & Translate works

  • StackShot recognizes text from captured content on-device.
  • On supported macOS versions, the app translates the recognized text in-app with Apple's public Translation framework. The system may prompt to download language resources the first time you use some language pairs.
  • According to Apple's framework documentation, Apple may collect usage and performance metrics that do not include the original content, such as the app bundle ID and source or target language.

What we do not do

  • We do not require an account for core screenshot workflows.
  • We do not start recording automatically in the background.
  • We do not ship automatic sync logic that uploads captures to a developer-operated server.
  • We do not sell your screenshots, OCR text, or usage habits.

Third-party and external services

When you use built-in OCR translation, the translation flow runs inside StackShot through Apple's public Translation framework. According to Apple's framework documentation, Apple may process limited usage and performance metrics that do not include the original content, such as the app bundle ID and source or target language.

This public site is hosted on GitHub Pages. GitHub may process basic web request logs for the page under its own policies.

Contact

If you have a question about this policy or want to report a product issue, use the support page or contact the project through GitHub Issues.

使用する権限

  • 画面収録: スクリーンショット、スクロールキャプチャ、取得済み画像の編集や OCR に使用します。

取得した内容の扱い

  • 編集、ウインドウ判定、OCR、ほとんどの画像処理はこの Mac 上で完結します。
  • 画像や文字をクリップボードへ書き込んだり、保存先へ書き出したりするのは、コピー、共有、保存、OCR 翻訳をあなたが選んだときだけです。

行わないこと

  • 基本的なスクリーンショット機能のためにアカウント作成を求めません。
  • バックグラウンドで自動的に録画を始めません。
  • 取得内容を開発者運営サーバーへ自動アップロードする同期ロジックを組み込みません。
  • スクリーンショット、OCR テキスト、利用傾向を販売しません。

外部サービスについて

内蔵 OCR 翻訳を使う場合、翻訳処理は Apple の公開 Translation フレームワークを通じてアプリ内で行われます。Apple の説明によると、Apple は元の内容を含まない利用状況や性能指標（アプリの Bundle ID、元言語／対象言語など）を処理する場合があります。

Política de privacidad de StackShot

StackShot es una herramienta de capturas local-first para macOS. Accedemos a permisos del sistema solo cuando usas funciones relacionadas de forma intencionada y procesamos el contenido capturado en el dispositivo siempre que es posible.

Resumen

StackShot no requiere una cuenta, no integra SDK publicitarios, no sube automáticamente tus capturas a un servidor remoto y no ofrece sincronización en la nube para el contenido capturado.

Permisos que usamos

  • Grabación de pantalla: se usa para capturas, capturas con desplazamiento y edición u OCR sobre el contenido capturado.

Cómo se maneja el contenido capturado

  • La edición, la detección de ventanas, el OCR y la mayor parte del procesamiento de imagen se realizan localmente en tu Mac.
  • Las imágenes o el texto solo se escriben en el portapapeles o se exportan al disco cuando eliges Copiar, Compartir, Guardar o Traducir con OCR.
  • Preferencias como idioma, visibilidad del Dock y atajos se guardan localmente en el Mac actual.

Cómo funciona Reconocer y traducir

  • StackShot reconoce en el dispositivo el texto del contenido capturado.
  • En las versiones compatibles de macOS, la app traduce el texto reconocido dentro de la aplicación con el framework público Translation de Apple. El sistema puede pedir descargar recursos de idioma la primera vez que uses algunos pares.
  • Según la documentación del framework de Apple, Apple puede recopilar métricas de uso y rendimiento que no incluyen el contenido original, como el identificador del bundle y el idioma de origen o destino.

Lo que no hacemos

  • No exigimos una cuenta para los flujos básicos de capturas.
  • No empezamos a grabar automáticamente en segundo plano.
  • No incorporamos lógica de sincronización automática que suba las capturas a un servidor operado por el desarrollador.
  • No vendemos tus capturas, el texto OCR ni tus hábitos de uso.

Servicios externos y de terceros

Cuando usas la traducción OCR integrada, el flujo se ejecuta dentro de StackShot mediante el framework público Translation de Apple. Según la documentación de Apple, Apple puede procesar métricas limitadas de uso y rendimiento que no incluyen el contenido original, como el identificador del bundle y el idioma de origen o destino.

StackShot Datenschutzrichtlinie

StackShot ist ein lokal orientiertes Screenshot-Tool für macOS. Wir greifen nur dann auf Systemberechtigungen zu, wenn du die entsprechenden Funktionen bewusst nutzt, und verarbeiten erfasste Inhalte nach Möglichkeit auf dem Gerät.

Kurzfassung

StackShot verlangt kein Konto, bindet keine Werbe-SDKs ein, lädt deine Screenshots nicht automatisch auf einen entfernten Server hoch und bietet keinen Cloud-Sync-Pfad für erfasste Inhalte.

Welche Berechtigungen wir verwenden

  • Bildschirmaufnahme: für Screenshots, Scroll-Screenshots sowie Bearbeitung oder OCR auf erfassten Inhalten.

Wie erfasste Inhalte behandelt werden

  • Bearbeitung, Fenstererkennung, OCR und der Großteil der Bildverarbeitung erfolgen lokal auf deinem Mac.
  • Bilder oder Text werden nur dann in die Zwischenablage geschrieben oder auf den Datenträger exportiert, wenn du Kopieren, Teilen, Sichern oder OCR-Übersetzen auswählst.
  • Einstellungen wie Sprache, Dock-Sichtbarkeit und Kurzbefehle werden lokal auf dem aktuellen Mac gespeichert.

Wie Erkennen und Übersetzen funktioniert

  • StackShot erkennt Text aus erfassten Inhalten direkt auf dem Gerät.
  • Auf unterstützten macOS-Versionen übersetzt die App den erkannten Text in der App mit Apples öffentlichem Translation-Framework. Beim ersten Verwenden mancher Sprachpaare kann das System Sprachressourcen herunterladen wollen.
  • Laut Apples Dokumentation kann Apple Nutzungs- und Leistungsmetriken erfassen, die den ursprünglichen Inhalt nicht enthalten, etwa die Bundle-ID der App sowie Quell- oder Zielsprache.

Was wir nicht tun

  • Wir verlangen kein Konto für zentrale Screenshot-Abläufe.
  • Wir starten keine Aufzeichnung automatisch im Hintergrund.
  • Wir liefern keine automatische Synchronisationslogik aus, die Aufnahmen auf einen von Entwicklern betriebenen Server hochlädt.
  • Wir verkaufen weder deine Screenshots noch OCR-Text oder Nutzungsgewohnheiten.

Drittanbieter und externe Dienste

Wenn du die integrierte OCR-Übersetzung nutzt, läuft der Übersetzungsvorgang innerhalb von StackShot über Apples öffentliches Translation-Framework. Laut Apples Dokumentation kann Apple begrenzte Nutzungs- und Leistungsmetriken verarbeiten, die den ursprünglichen Inhalt nicht enthalten, etwa die Bundle-ID der App sowie Quell- oder Zielsprache.

StackShot 개인정보 처리방침

StackShot은 macOS용 로컬 우선 스크린샷 도구입니다. 관련 기능을 사용자가 직접 사용할 때만 시스템 권한에 접근하며, 가능하면 캡처한 내용을 기기에서 처리합니다.

요약

StackShot은 계정을 요구하지 않고, 광고 SDK를 포함하지 않으며, 스크린샷을 원격 서버에 자동 업로드하지 않고, 캡처 내용을 위한 클라우드 동기화 경로도 제공하지 않습니다.

사용하는 권한

  • 화면 기록: 스크린샷, 스크롤 캡처, 캡처한 내용에 대한 편집 및 OCR에 사용됩니다.

캡처한 내용을 처리하는 방식

  • 편집, 창 감지, OCR, 대부분의 이미지 처리는 현재 Mac에서 로컬로 수행됩니다.

우리가 하지 않는 것

  • 핵심 스크린샷 기능을 위해 계정을 요구하지 않습니다.
  • 백그라운드에서 자동으로 녹화를 시작하지 않습니다.
  • 캡처를 개발자 운영 서버로 업로드하는 자동 동기화 로직을 포함하지 않습니다.

Política de privacidade do StackShot

O StackShot é uma ferramenta de captura local-first para macOS. Acessamos permissões do sistema apenas quando você usa intencionalmente os recursos relacionados e processamos o conteúdo capturado no dispositivo sempre que possível.

Resumo

O StackShot não exige conta, não incorpora SDKs de anúncios, não envia automaticamente suas capturas para um servidor remoto e não oferece sincronização em nuvem para o conteúdo capturado.

Permissões que usamos

  • Gravação de Tela: usada para capturas, capturas com rolagem e edição ou OCR sobre o conteúdo capturado.

Como o conteúdo capturado é tratado

  • Edição, detecção de janelas, OCR e a maior parte do processamento de imagem acontecem localmente no seu Mac.
  • Imagens ou texto só são gravados na área de transferência ou exportados para disco quando você escolhe Copiar, Compartilhar, Salvar ou Traduzir com OCR.
  • Preferências como idioma, visibilidade do Dock e atalhos são armazenadas localmente no Mac atual.

Como funciona Reconhecer e traduzir

  • O StackShot reconhece o texto do conteúdo capturado no próprio dispositivo.
  • Nas versões compatíveis do macOS, o app traduz o texto reconhecido dentro do aplicativo usando o framework público Translation da Apple. O sistema pode solicitar o download de recursos de idioma na primeira vez que você usar alguns pares.
  • Segundo a documentação do framework da Apple, a Apple pode coletar métricas de uso e desempenho que não incluem o conteúdo original, como o identificador do app e o idioma de origem ou destino.

O que não fazemos

  • Não exigimos conta para os fluxos principais de captura.
  • Não iniciamos gravações automaticamente em segundo plano.
  • Não enviamos lógica de sincronização automática que faça upload das capturas para um servidor operado pelo desenvolvedor.
  • Não vendemos suas capturas, texto OCR nem hábitos de uso.

Serviços externos e de terceiros

Quando você usa a tradução OCR integrada, o fluxo roda dentro do StackShot por meio do framework público Translation da Apple. Segundo a documentação da Apple, a Apple pode processar métricas limitadas de uso e desempenho que não incluem o conteúdo original, como o identificador do app e o idioma de origem ou destino.

Este site público é hospedado no GitHub Pages. O GitHub pode processar registros básicos de solicitações web sob suas próprias políticas.

Политика конфиденциальности StackShot

StackShot — это локальный инструмент для скриншотов на macOS. Мы обращаемся к системным разрешениям только тогда, когда вы сами используете соответствующие функции, и по возможности обрабатываем захваченный контент прямо на устройстве.

Коротко

StackShot не требует учётной записи, не содержит рекламных SDK, не загружает ваши снимки автоматически на удалённый сервер и не предлагает облачную синхронизацию для захваченного контента.

Какие разрешения мы используем

  • Запись экрана: используется для снимков, захвата с прокруткой, а также для редактирования и OCR на захваченном содержимом.

Как обрабатывается захваченный контент

  • Редактирование, определение окон, OCR и большая часть обработки изображений выполняются локально на вашем Mac.
  • Изображения или текст записываются в буфер обмена или экспортируются на диск только когда вы выбираете Копировать, Поделиться, Сохранить или OCR-перевод.
  • Настройки вроде языка, отображения Dock и горячих клавиш хранятся локально на текущем Mac.

Как работает «Распознать и перевести»

  • StackShot распознаёт текст в захваченном содержимом прямо на устройстве.
  • На поддерживаемых версиях macOS приложение переводит распознанный текст внутри себя через публичный фреймворк Translation от Apple. При первом использовании некоторых языковых пар система может предложить загрузить языковые ресурсы.
  • Согласно документации Apple, компания может собирать метрики использования и производительности, не содержащие исходного контента, например идентификатор пакета приложения и исходный или целевой язык.

Чего мы не делаем

  • Мы не требуем учётную запись для основных сценариев работы со скриншотами.
  • Мы не начинаем запись автоматически в фоне.
  • Мы не поставляем автоматическую синхронизацию, которая загружает снимки на сервер, управляемый разработчиком.
  • Мы не продаём ваши снимки, OCR-текст или данные о привычках использования.

Сторонние и внешние сервисы

Когда вы используете встроенный OCR-перевод, процесс выполняется внутри StackShot через публичный фреймворк Translation от Apple. Согласно документации Apple, компания может обрабатывать ограниченные метрики использования и производительности, не содержащие исходный контент, например идентификатор пакета приложения и исходный или целевой язык.

Этот публичный сайт размещён на GitHub Pages. GitHub может обрабатывать базовые журналы веб-запросов в соответствии со своими правилами.

سياسة خصوصية StackShot

StackShot أداة لالتقاط الشاشة على macOS تضع المعالجة المحلية أولًا. لا نطلب أذونات النظام إلا عند استخدامك للميزات ذات الصلة، ونفضّل معالجة المحتوى الملتقط على جهازك قدر الإمكان.

الخلاصة السريعة

لا يتطلب StackShot إنشاء حساب، ولا يتضمن حزم إعلانات، ولا يرفع لقطاتك تلقائيًا إلى خادم بعيد، ولا يوفر مزامنة سحابية لمحتوى اللقطات.

ما الأذونات التي نستخدمها

  • تسجيل الشاشة: يُستخدم لالتقاط الصور، واللقطات الطويلة بالتمرير، وكذلك للتحرير وOCR على المحتوى الملتقط.

كيف نتعامل مع المحتوى الملتقط

  • يتم تنفيذ تحرير اللقطات، والتعرّف على النوافذ، وOCR، ومعظم معالجة الصور محليًا على جهاز Mac الخاص بك.
  • لا تُكتب الصور أو النصوص إلى الحافظة أو إلى ملف تصدير إلا عندما تختار النسخ أو المشاركة أو الحفظ أو ترجمة OCR.
  • تُحفظ الإعدادات مثل اللغة، وإظهار Dock، واختصارات لوحة المفاتيح محليًا على جهاز Mac الحالي فقط.

كيف تعمل ميزة «التعرّف والترجمة»

  • يتعرّف StackShot أولًا على النص داخل المحتوى الملتقط مباشرة على الجهاز.
  • على إصدارات macOS المدعومة، يترجم التطبيق النص المتعرّف عليه داخله عبر إطار Translation الرسمي من Apple. وقد يطلب النظام تنزيل موارد اللغة عند أول استخدام لبعض أزواج اللغات.
  • وفقًا لوثائق Apple، قد تجمع الشركة مقاييس استخدام وأداء لا تتضمن المحتوى الأصلي، مثل معرّف حزمة التطبيق ولغة المصدر أو الهدف.

ما الذي لا نقوم به

  • لا نطلب حسابًا لاستخدام سيناريوهات اللقطات الأساسية.
  • لا نبدأ تسجيل الشاشة تلقائيًا في الخلفية.
  • لا نوفر منطق مزامنة تلقائي يرفع لقطاتك إلى خادم يديره المطور.
  • لا نبيع لقطاتك أو نص OCR أو بيانات عادات الاستخدام.

الأطراف الثالثة والخدمات الخارجية

عند استخدام ترجمة OCR المدمجة، تتم عملية الترجمة داخل StackShot عبر إطار Translation الرسمي من Apple. ووفقًا لوثائق Apple، قد تُعالج بعض مقاييس الاستخدام والأداء المحدودة التي لا تحتوي على النص الأصلي، مثل معرّف حزمة التطبيق ولغة المصدر أو الهدف.

هذا الموقع العام مستضاف على GitHub Pages. وقد يعالج GitHub سجلات طلبات الويب الأساسية وفقًا لسياساته الخاصة.

Kebijakan Privasi StackShot

StackShot adalah alat tangkapan layar lokal-pertama untuk macOS. Kami mengakses izin sistem hanya ketika Anda menggunakan fitur terkait.

Versi singkat

StackShot tidak memerlukan akun, tidak menyematkan SDK iklan, tidak mengupload tangkapan layar ke server jarak jauh secara otomatis.

Izin yang kami gunakan

  • Perekaman Layar: untuk tangkapan layar, tangkapan gulir, dan OCR.

  • Pengeditan, deteksi jendela, OCR, dan pemrosesan gambar dilakukan secara lokal.
  • Gambar atau teks ditulis ke clipboard hanya saat Anda memilih Salin, Bagikan, atau Simpan.

Cara Kenali & Terjemahkan bekerja

  • StackShot mengenali teks dari konten yang diambil di perangkat.
  • Pada versi macOS yang didukung, menggunakan framework Translation Apple.

Yang tidak kami lakukan

  • Tidak memerlukan akun untuk fitur utama.
  • Tidak merekam otomatis di latar belakang.
  • Tidak menyinkronkan ke server pengembang secara otomatis.
  • Tidak menjual data Anda.

Informativa sulla Privacy di StackShot

StackShot è uno strumento di screenshot locale-first per macOS. Accediamo alle autorizzazioni di sistema solo quando utilizzi le funzionalità correlate.

Versione breve

StackShot non richiede un account, non integra SDK pubblicitari, non carica automaticamente i tuoi screenshot su un server remoto.

Autorizzazioni che utilizziamo

  • Registrazione schermo: per screenshot, cattura scorrevole ed OCR.

Come viene gestito il contenuto catturato

  • Modifica, rilevamento finestre, OCR ed elaborazione immagini avvengono localmente.
  • Immagini o testo vengono scritti negli appunti solo quando scegli Copia, Condividi o Salva.

Come funziona Riconosci e Traduci

  • StackShot riconosce il testo sul dispositivo.
  • Nelle versioni macOS supportate, la traduzione avviene tramite il framework Translation di Apple.

Cosa non facciamo

  • Non richiediamo un account per le funzionalità principali.
  • Non registriamo automaticamente in background.
  • Non sincronizziamo con server del developer.
  • Non vendiamo i tuoi dati.

Privacybeleid van StackShot

StackShot is een lokaal-first screenshot-tool voor macOS. We hebben alleen toegang tot systeemmachtigingen wanneer u de betreffende functies gebruikt.

Korte versie

StackShot vereist geen account, integreert geen advertentie-SDK's, uploadt uw screenshots niet automatisch naar een externe server.

Machtigingen die we gebruiken

  • Schermopname: voor screenshots, schuivende opname en OCR.

Hoe vastgelegde inhoud wordt verwerkt

  • Bewerking, vensterdetectie, OCR en beeldverwerking lokaal op uw Mac.
  • Afbeeldingen of tekst worden naar het klembord geschreven alleen wanneer u Kopiëren, Delen of Opslaan kiest.

Hoe Herkennen en Vertalen werkt

  • StackShot herkent tekst op het apparaat.
  • Op ondersteunde macOS-versies via Apple's Translation-framework.

Wat we niet doen

  • We vereisen geen account voor kernfuncties.
  • We starten niet automatisch op de achtergrond op.
  • We synchroniseren niet met servers van de ontwikkelaar.
  • We verkopen uw gegevens niet.
